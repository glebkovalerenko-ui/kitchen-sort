# GDD-Lite: Kitchen Sort

## 1. Обзор Игры (High Concept)

*   **Название Игры:** Kitchen Sort
*   **Жанр:** Puzzle, Merge-2, Casual
*   **Концепция:** Расслабляющая игра-головоломка, в которой игроки объединяют базовые ингредиенты на кухонном столе, чтобы открывать новые рецепты, выполнять заказы и постепенно улучшать свою кухню.
*   **Целевая Аудитория:** Казуальные игроки, любители головоломок и игр на организацию (Merge Mansion, Bejeweled), которым нравится уютная атмосфера и тема кулинарии.
*   **Платформа:** Web (Яндекс Игры), с дизайном, ориентированным на мобильные устройства (Mobile-First).

## 2. Ключевые Особенности (Key Features)

*   **Простая Механика Слияния (Merge-2):** Интуитивно понятный геймплей, где игрок перетаскивает предметы друг на друга на сетке 5x5 для создания новых.
*   **Система Рецептов и Открытий:** Более 20 уникальных блюд для открытия, что мотивирует игроков экспериментировать и заполнять свою "Книгу Рецептов".
*   **Прогрессирующие Генераторы:** Два основных источника ресурсов (Курятник и Теплица), которые можно улучшать, увеличивая их вместимость и скорость производства.
*   **Динамичная Система Заказов:** Основной драйвер игры, который ставит перед игроком четкие цели и является главным источником дохода.
*   **Бесконечный Геймплей:** В игре нет состояния "Game Over". Игрок может развивать свою кухню бесконечно, фокусируясь на оптимизации и выполнении все более сложных заказов.
*   **Соревновательный Элемент:** Двойная система лидербордов: вечный "Личный Рекорд" и еженедельные турниры с наградами для лучших игроков.

## 3. Игровой Процесс (Gameplay)

### Основной Игровой Цикл (Core Loop)

Игровой процесс строится на простом и затягивающем цикле:

| Шаг | Действие Игрока | Цель / Результат |
| :--- | :--- | :--- |
| **1. Получение** | Собирает базовые ингредиенты (Яйца, Томаты) из Генераторов. | Получение ресурсов для слияния. |
| **2. Слияние** | Объединяет предметы на игровом поле. | Открытие новых рецептов, получение очков и монет. |
| **3. Выполнение**| Использует созданные блюда для выполнения заказов. | Получение большого количества монет. |
| **4. Улучшение** | Тратит монеты на улучшение Генераторов и Гаджетов. | Ускорение прогресса и увеличение эффективности. |
| **(Повтор)**| Возвращается к шагу 1 с новыми возможностями. | Долгосрочное вовлечение. |

### Начальный Опыт Игрока (First Time User Experience - FTUE)

Первые 15-20 минут игры спроектированы так, чтобы максимизировать вовлечение и минимизировать ожидание:

*   **"Быстрый Старт":** Игрок начинает с большим количеством предметов и зарядов генераторов.
*   **Сверхбыстрые Таймеры:** Первые перезарядки генераторов и кулдауны заказов длятся всего несколько секунд.
*   **Обучающая Цепочка Заказов:** Первые три заказа предопределены, чтобы плавно познакомить игрока с механикой.

## 4. Экономика и Монетизация

### Игровая Валюта

*   **Монеты (Coins):** Основная и единственная валюта. Используется для всех улучшений.
    *   **Источники:** Слияние предметов, выполнение заказов, просмотр рекламы.
    *   **Потребители (Sinks):** Улучшение Генераторов, улучшение Гаджетов.

### Монетизация

Модель Free-to-Play, основанная на просмотре рекламы.

*   **Видео с Вознаграждением (Rewarded Ads):**
    *   Мгновенное заполнение всех слотов в генераторе (Полить/Накормить всех).
    *   Очистка игрового поля.
    *   *В будущем: удвоение наград за заказы, временные бусты.*

*   **Межстраничная Реклама (Interstitial Ads):**
    *   Показывается между игровыми сессиями (например, при возвращении в игру после долгого отсутствия).
    *   Имеет длинный кулдаун (**3 минуты**), чтобы не раздражать игрока.

## 5. Арт и Звук

*   **Визуальный Стиль:** Яркая, чистая 2D-графика в мультяшном стиле. Уютная и дружелюбная атмосфера. Цветовая палитра теплая, аппетитная. Интерфейс простой, с большими, понятными кнопками.
*   **Звуковое Оформление:**
    *   **SFX:** "Сочные", приятные звуки для ключевых действий: хлопок при слиянии, звон монет, шелест при перетаскивании.
    *   **Музыка:** Расслабляющая, фоновая "cozy" мелодия, которая не отвлекает от процесса.
